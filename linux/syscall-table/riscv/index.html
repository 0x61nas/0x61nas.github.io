Searchable Linux Syscall Table RISC-V

This table is derived from the unistd.h file in the Linux 7.0 kernel source, and the syscalls.h header file. The generator is available on GitHub.

Syscalls are implemented in functions named as in the Entry point column, generated with DEFINE_SYSCALLx macros. For more information, see Documentation/process/adding-syscalls.rst.

To learn more, read the syscall(2) and syscalls(2) man pages.

This table is available for X86-64, ARM64, and RISCV.

Click on a row to reveal the arguments list. Search using the fuzzy filter box or the Ctrl+F.
