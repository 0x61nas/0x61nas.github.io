Searchable FreeBSD Syscall Table ARM64

Derived from sys/kern/syscalls.master (FreeBSD 15.0, releng/15.0). The file is ABI-common, so the syscall list is the same on every architecture; only the registers differ. See the Arm 64-bit Procedure Call Standard (AAPCS64).

This table is available for X86-64, ARM64, and RISCV64.

On FreeBSD you can issue syscalls directly from assembly: number in %x8, arguments in x0, x1, x2, x3, x4, x5, result in %x0 (carry flag set and error number in %x0 on error). Click a row for arguments and details; filter with the box below, Ctrl+F, or grab the CSV.

Type field values (a syscall can have more than one, separated by |):

  • STD — always included
  • CAPENABLED — allowed in capability mode
  • COMPAT — included only on COMPAT kernels
  • COMPAT4-14 — included only for the matching COMPAT_FREEBSD<n> ABI
  • OBSOL — obsolete, not included in the system
  • RESERVED — reserved for local or vendor use
  • UNIMPL — not implemented, placeholder only
  • NOSTD — implemented as a loadable module
  • NODEF — entry only, no structure or prototype is generated
  • NOARGS — like STD, but no argument structure is generated
  • NOPROTO — like STD, but no prototype is generated
  • NOLIB — no stubs are generated in libc or libsys
  • NOTSTATIC — the syscall is loadable
  • NORETURN — the syscall does not return
  • SYSMUX — syscall multiplexer, handled in MD syscall code
