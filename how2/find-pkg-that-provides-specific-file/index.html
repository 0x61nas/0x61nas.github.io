pacman

First update the information database

doas pacman -Fy

Then you can search for the file with

pacman -F $filename

To search with a regular exepretion use:

pacman -Fx $expr

the google way:

site:www.archlinux.org/packages/ bin/filename

and in case it is in AUR instead of an official package:

site:aur.archlinux.org/packages/ bin/filename
